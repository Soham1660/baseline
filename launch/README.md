## Re-render with the live URL (≈3 minutes)

```bash
cd launch/remotion
URL='baseline-vby8.onrender.com'
npx remotion render Demo60 ../videos/baseline-demo-60s.mp4 --props="{\"appUrl\":\"$URL\",\"withScore\":true}" --codec=h264 --crf=18 --pixel-format=yuv420p --audio-codec=aac
npx remotion render TeaserVertical ../videos/baseline-teaser-vertical.mp4 --props="{\"appUrl\":\"$URL\",\"withScore\":true}" --codec=h264 --crf=18 --pixel-format=yuv420p --audio-codec=aac
```

Open the editor with `npx remotion studio` in `launch/remotion`.

## Re-capture footage

```bash
# terminal 1 (repo root)
npm run build && NODE_ENV=production PORT=3100 node server.ts
# terminal 2
cd launch/scripts && npm install && node capture.mjs http://localhost:3100
```
Then run `./transcode-clips.sh` (converts the .webm captures to 30 fps H.264 in `remotion/public/clips/`).

## Media & licensing

- All interface footage: real Playwright screen recordings and screenshots of BASELINE.
- Walkthrough frames: BASELINE's own synthetic sample videos (`public/samples`, generated by `scripts/generate-samples.mjs`).
- Fonts: Newsreader, Inter, IBM Plex Mono (SIL Open Font License, via Google Fonts), the same ones the app uses.
- Music: original, synthesized by `scripts/gen_score.py`.
- No stock media, no AI voices, no generated people.
- Remotion is free for individuals and teams of up to 3 (see remotion.dev/license).

## Git

Large media (`videos/`, `recordings/`, `remotion/public/clips`, `remotion/node_modules`, …) is git-ignored by `launch/.gitignore`. Host the videos on YouTube or Drive, not in the repo.
